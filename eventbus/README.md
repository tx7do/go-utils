# eventbus

English | [简体中文](README.zh-CN.md)

An in-process publish/subscribe event bus: synchronous/async/once subscriptions, dispatch by event type, multi-bus management and middleware composition.

## Features

- **EventBus** (`eventbus.go`): synchronous / async / one-time (once) subscriptions dispatched by event type; a failing handler does not block the others; `PublishAsync` runs on a dedicated background context with a 30-second timeout, unaffected by caller cancellation;
- **Handler combinators** (`handler.go`): `AsyncHandler` (runs in a goroutine) / `ChainHandler` (sequential chain) / `FilterHandler` (conditional);
- **Manager** (`manager.go`): manages multiple named buses; empty names and `"global"` are special-cased to return the global bus, avoiding the classic mistake of "publish to global" and "subscribe on Global()" landing on two different instances;
- **Middleware** (`middleware.go`): logging / recover / timeout / retry / metrics, composed with `Chain`;
- **Events carry identity**: `NewEvent` auto-generates a unique ID (timestamp + 8 random chars) and a `Timestamp`.

## Quick Start

```go
package main

import (
	"context"
	"fmt"

	"github.com/tx7do/kratos-bootstrap/logger"
	"github.com/tx7do/go-utils/eventbus"
)

func main() {
	bus := eventbus.NewEventBus(logger.NopLogger())
	defer bus.Close()

	_ = bus.Subscribe("order.created", eventbus.EventHandlerFunc(func(ctx context.Context, ev *eventbus.Event) error {
		var order map[string]any
		if err := ev.GetData(&order); err != nil {
			return err
		}
		fmt.Println("order created:", order["order_id"])
		return nil
	}))

	ctx := context.Background()
	_ = bus.Publish(ctx, eventbus.NewEvent("order.created", map[string]any{"order_id": "order-123"}))
}
```

> Note: the constructor takes a `logger.Logger` interface. The kratos-bootstrap/logger this module depends on has no `DefaultLogger` variable — use `logger.NopLogger()` in tests / bare processes and `logger.GetLogger()` to plug into framework logging.

Event types are arbitrary strings (by convention a `"domain.action"` style); the payload `Event.Data` is `any`, and subscribers use `Event.GetData(&v)` to round-trip it through JSON — publish a struct on one side, decode into an identically shaped struct on the other.

## API Reference

### EventBus (`eventbus.go`)

```go
type EventBus interface {
    Subscribe(eventType string, handler Handler) error       // synchronous subscription
    SubscribeAsync(eventType string, handler Handler) error  // async subscription (Subscribe + AsyncHandler wrapper)
    SubscribeOnce(eventType string, handler Handler) error   // one-shot subscription: removed after first fire
    Unsubscribe(eventType string, handler Handler) error     // removes by pointer identity; "handler not found" otherwise
    Publish(ctx context.Context, event *Event) error         // synchronous publish: invokes every handler in turn
    PublishAsync(ctx context.Context, event *Event) error    // async publish: returns immediately, publishes in a goroutine
    Close() error                                            // closes the bus and clears all subscriptions
}

func NewEventBus(logger logger.Logger) EventBus
```

Extra methods (on the concrete `*DefaultEventBus`):

```go
func (eb *DefaultEventBus) GetSubscriberCount(eventType string) int // regular + once subscriber count
func (eb *DefaultEventBus) GetEventTypes() []string                 // all event types that have subscribers
```

### Event (`event.go`)

```go
type Event struct {
    ID        string            // auto-generated by NewEvent: timestamp + 8 random chars
    Type      string            // event type
    Source    string            // origin marker
    Data      any               // payload
    Metadata  map[string]string // extra metadata
    Timestamp time.Time         // set to time.Now() by NewEvent
    Priority  int               // priority (pairs well with FilterHandler)
}

func NewEvent(eventType string, data any) *Event          // auto ID/Timestamp, Priority 0
func (e *Event) WithSource(source string) *Event          // chained source setter
func (e *Event) WithPriority(priority int) *Event         // chained priority setter
func (e *Event) WithMetadata(key, value string) *Event    // chained metadata append
func (e *Event) GetData(v any) error                      // decode Data into v via a JSON round-trip
func (e *Event) Clone() *Event                            // deep copy (Metadata copied; Data stays a shallow reference)
```

### Manager (`manager.go`)

```go
func NewManager(logger logger.Logger) *Manager

func (m *Manager) GetBus(name string) EventBus       // ""/"global" return the global bus; unknown names are created on demand
func (m *Manager) Global() EventBus                  // the global bus
func (m *Manager) Publish(ctx context.Context, busName string, event *Event) error
func (m *Manager) PublishGlobal(ctx context.Context, event *Event) error
func (m *Manager) Subscribe(busName, eventType string, handler Handler) error
func (m *Manager) SubscribeGlobal(eventType string, handler Handler) error
func (m *Manager) GetStats() map[string]any          // total_buses / buses{event_types} / global_bus{event_types}
func (m *Manager) Close() error                      // closes every named bus and the global bus
```

### Handler combinators (`handler.go`)

```go
type Handler interface { Handle(ctx context.Context, event *Event) error }
type EventHandlerFunc func(ctx context.Context, event *Event) error // adapts functions to Handler

func NewAsyncHandler(handler Handler) *AsyncHandler       // Handle returns immediately; the handler runs in a new goroutine
func NewChainHandler(handlers ...Handler) *ChainHandler   // runs in order, short-circuits on the first error
func NewFilterHandler(filter func(*Event) bool, handler Handler) *FilterHandler // skips when filter is false
```

### Middleware (`middleware.go`)

```go
type Middleware func(Handler) Handler

func LoggingMiddleware(logger *logger.Helper) Middleware    // logs start / success / failure
func RecoveryMiddleware(logger *logger.Helper) Middleware   // recovers panics → *PanicError
func TimeoutMiddleware(timeout time.Duration) Middleware    // deadline exceeded → *TimeoutError
func RetryMiddleware(maxRetries int, delay time.Duration) Middleware // retries failures with a fixed delay
func MetricsMiddleware(logger *logger.Helper) Middleware    // logs processing duration
func Chain(middlewares ...Middleware) Middleware            // compose: earliest listed = outermost
```

The two error types middleware can produce:

```go
type PanicError struct{ Value any }                                    // Error() == "panic in event handler"
type TimeoutError struct{ EventID, EventType string; Timeout time.Duration } // Error() == "event handling timeout"
```

## Notes / Caveats

- **A failing handler does not block others**: `Publish` invokes every handler in order; a failure is only logged and the rest keep running. The publisher never sees handler errors (`Publish` returns nil) — if you must observe errors, handle them inside the handler itself rather than via the bus;
- **No subscribers is not an error**: publishing to an event type with no subscribers simply returns nil;
- **Once semantics**: handlers registered via `SubscribeOnce` are removed as a whole (per event type) after the first `Publish`;
- **PublishAsync's timeout is independent**: the background goroutine uses `context.Background()` + a 30-second timeout, so cancelling the caller's ctx does not affect an in-flight async publish. The publish itself still walks handlers synchronously (per-handler async comes from `SubscribeAsync` / `AsyncHandler`);
- **Reusing after Close errors**: `Subscribe` / `Publish` return "event bus is closed" after `Close`; a second `Close` returns "event bus already closed";
- **`Unsubscribe` only affects regular subscriptions** and matches by handler pointer identity (wrapping the same function again does not count — keep the original reference); once subscriptions cannot be removed individually;
- **`Chain` ordering**: `Chain(a, b)(h)` executes a → b → h — the middleware listed first is outermost;
- **The timeout middleware does not kill the handler**: on timeout `TimeoutMiddleware` returns `*TimeoutError`, but the timed-out handler goroutine keeps running (a consequence of channel semantics); for hard interruption, respond to ctx inside the handler itself.
